# BlackoutMac 사용 안내

[빠른 시작](../ko/README.md#빠른-시작) · [English](README.md) · [다운로드](https://github.com/baba9811/blackout-mac/releases)

## 설치

1. GitHub Releases에서 Universal DMG를 다운로드합니다. 배포본은 실제 환경 검증이 진행 중인 미리보기 버전입니다.
2. DMG를 열고 **Blackout.app**을 **Applications**로 드래그합니다.
3. 앱을 엽니다. Apple이 악성 소프트웨어 여부를 확인할 수 없다고 하면 <strong>휴지통으로 이동 대신 완료</strong>를 누르세요. 공식 GitHub에서 받은 앱이라면 <strong>시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기</strong>에서 Blackout을 선택하고 인증해 실행합니다.
4. 메뉴 막대의 <strong>Blackout 아이콘 → 설정… → 입력 차단 → 입력 권한 설정 열기…</strong>를 누르고, 열린 시스템 패널에서 Blackout을 허용합니다.

앱의 버튼은 macOS 버전에 맞는 입력 제어 권한 패널을 엽니다. 보조 기능을 설정하는 일반 ‘손쉬운 사용’ 메뉴와는 별도의 권한 목록입니다. [Apple의 앱 제어 권한 안내](https://support.apple.com/ko-kr/guide/mac-help/mh43185/mac)도 참고하세요.

macOS 13 이상, Apple Silicon 및 Intel Mac을 지원합니다. 터미널이나 개발 도구는 필요하지 않습니다.
미리보기 배포본은 **Developer ID 서명과 Apple 공증이 없어** 첫 실행에 이 경고가 표시될 수 있습니다. 자체 서명은 업데이트 간 앱 식별 정보를 유지하며 Apple 승인을 의미하지 않습니다. <strong>그래도 열기</strong>는 실행을 시도한 뒤 약 1시간 동안 표시됩니다. 손상·악성 소프트웨어 감지 등 다른 경고는 [Apple의 경고 안내](https://support.apple.com/ko-kr/102445)를 확인하세요. Gatekeeper는 켜 둡니다.

## 기본 사용과 설정

- **검은 화면 시작:** Control + Option + B 또는 메뉴 막대 Blackout → 지금 화면 가리기.
- **상태 아이콘:** 기본 달 모양에 비밀번호 보호가 켜지면 작은 자물쇠 배지가 붙습니다. 비밀번호 설정을 저장하면 즉시 바뀝니다. 화면 차단 중에는 메뉴 막대도 숨겨집니다.
- **Dock:** 설정 창을 열었을 때만 달 아이콘이 나타납니다. 설정 창을 닫아도 메뉴 막대에서 계속 실행됩니다.
- **해제:** 마우스를 움직이거나 클릭·스크롤·키 입력. 비밀번호 보호를 켠 경우에는 비밀번호를 입력해야 합니다.

- **자동 실행:** 설정에서 로그인 시 자동 실행을 켭니다. 로그인 후 메뉴 막대에서 대기하며, 화면을 자동으로 검게 만들지는 않습니다.
- **언어:** 기본값은 OS 언어입니다. 설정에서 32개 언어 중 선택하면 즉시 적용됩니다.

## AI 작업

Mac이 깨어 있는 동안 CLI·파일·MCP 작업은 계속할 수 있습니다. Blackout은 앱을 일시 정지하거나 Mac의 잠자기를 방지하지 않습니다. 화면을 가린 상태에서 Codex의 셸 작업과 앱 내 브라우저 동작을 확인했습니다. 스크린샷이나 데스크톱 입력을 쓰는 자동화는 검은 화면을 보거나 입력이 차단될 수 있으며, 다른 네이티브 앱 경로와 Claude 작업은 검증하지 않았습니다. 도구별 기능은 [Computer Use](https://learn.chatgpt.com/docs/computer-use)와 [Claude Code 안내](https://code.claude.com/docs/en/how-claude-code-works)를 참고하세요.

## 비밀번호와 복구

- **비밀번호:** 선택 사항이며 기본적으로 꺼져 있습니다. 설정의 **화면 해제 시 비밀번호 요구** 스위치를 사용합니다. 켜면 새 비밀번호 설정창이, 끄면 현재 비밀번호 확인창이 열립니다. 저장에 성공해야 스위치가 바뀌며, 취소하면 원래 상태를 유지합니다. 보호가 켜져 있을 때 **비밀번호 변경…** 버튼과 **비밀번호를 잊으셨나요…** 복구 링크가 표시됩니다.
- **해제 취소:** 해제창에서 **취소**를 누르면 검은 화면으로 돌아갑니다. 이후 2초 동안은 키보드나 마우스를 움직여도 입력창이 다시 열리지 않으며, 2초가 지나면 평소처럼 입력으로 열 수 있습니다.
- **비상 탈출:** **Escape를 3초간 누르면** 비밀번호 사용 여부와 관계없이 화면 가리기를 끝냅니다. 앱이 응답하지 않으면 앱을 종료하므로 다시 실행하세요. 비상 탈출은 앱 비밀번호를 의도적으로 우회하며 저장된 비밀번호를 지우지는 않습니다.
- **비밀번호를 잊었다면:** 화면 가리기에서 나온 뒤 <strong>설정… → 비밀번호를 잊으셨나요…</strong>를 선택하고 Touch ID 또는 Mac 로그인 암호로 인증합니다. Blackout 비밀번호만 초기화하고 언어·로그인 설정은 유지합니다. 인증을 취소하면 변경하지 않습니다.
- **입력 언어 전환:** 해제창에서 Control + Space를 누르면 활성화한 키보드 입력 소스를 전환합니다.

## 입력 차단과 보안

입력 차단 권한이 없거나 차단을 시작하지 못하면 검은 화면을 띄우지 않습니다. 차단 중에는 원본 키보드·마우스 이벤트를 소비하고, 해제창에 필요한 입력만 Blackout에 전달합니다. 차단이 중단되면 화면을 다시 보여주고 오류를 알립니다.

앱 내부의 화면 가리기 기능이므로 macOS 보안 잠금을 대체하지 않습니다. 선택형 비밀번호는 Blackout을 통한 일반적인 화면 가림 해제에만 적용됩니다. macOS 손쉬운 사용 권한을 이미 받은 자동화 도구는 가려진 다른 앱의 내용을 읽거나 해당 앱을 제어할 수 있습니다. 강제 종료, 다른 권한 있는 프로그램, macOS 보안 화면·보안 입력은 운영체제가 제어합니다. 사용자 세션을 보호하려면 <strong>macOS 화면 잠금(Control + Command + Q)</strong>을 사용하세요. [Apple의 키보드 단축키 안내](https://support.apple.com/ko-kr/102650)에서도 확인할 수 있습니다.

비밀번호 원문은 저장하지 않으며 무작위 salt와 PBKDF2 검증값을 사용합니다. 설정은 이 Mac에 저장되고, 앱 자체의 서버·분석 수집 기능은 없습니다.

설정의 <strong>업데이트 확인…</strong>을 눌렀을 때만 GitHub의 공개 릴리스 정보를 조회합니다. 비밀번호나 설정은 전송하지 않습니다.

## 업데이트

1. 설정에서 현재 버전을 확인하고 <strong>업데이트 확인…</strong>을 누릅니다. 새 버전의 릴리스 페이지를 열어 DMG를 다운로드하거나 Releases에서 직접 받습니다.
2. 화면 가림을 해제한 뒤 메뉴 막대에서 **Blackout 종료**를 선택합니다.
3. **기존 앱과 같은 폴더의 Blackout.app을 새 앱으로 교체**하고 다시 실행합니다.

비밀번호와 언어 설정은 앱과 별도로 저장되어 유지됩니다. 교체 후 로그인 자동 실행 상태도 확인하세요. 서명 식별 정보가 바뀌면 입력 제어 권한을 한 번 다시 승인해야 할 수 있습니다. 모든 업데이트마다 필요한 절차는 아닙니다. 현재는 새 DMG로 직접 교체하는 업데이트 방식입니다.

**이미 권한을 켰는데도 화면 가리기가 안 된다면:** Blackout을 종료하고, 입력 제어 권한 목록에서 Blackout을 제거한 뒤 현재 설치된 **Blackout.app**을 다시 추가해 허용하고 앱을 재실행하세요. 업데이트로 앱 서명이 바뀌면 스위치가 켜져 있어도 이전 빌드에 부여한 권한만 남아 있을 수 있습니다.

소스 빌드, 검증, 비밀번호 초기화, 삭제는 [개발자 문서](../development.md), 서명과 배포 검증은 [배포 문서](../distribution.md)를 참고하세요.
