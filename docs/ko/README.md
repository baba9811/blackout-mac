# BlackoutMac 사용 안내

**화면은 검게, 복귀 방식은 원하는 대로.** 단축키 하나로 연결된 화면을 가리고 입력을 차단합니다. 바로 복귀하거나, 선택형 비밀번호를 설정해 확인 후 복귀할 수 있습니다. 메뉴 막대에서 비밀번호 사용 여부를 확인하고, 로그인 자동 실행과 32개 언어를 설정할 수 있습니다.

[다국어 설명서](https://baba9811.github.io/blackout-mac/ko/) · [다운로드](https://github.com/baba9811/blackout-mac/releases)

## 설치

1. GitHub Releases에서 Universal DMG를 다운로드합니다. 최초 배포본은 실제 환경 검증이 진행 중인 미리보기 버전입니다.
2. DMG를 열고 **Blackout.app**을 **Applications**로 드래그합니다.
3. 앱을 연 뒤 메뉴 막대의 **Blackout 아이콘 → 설정… → 입력 차단**에서 손쉬운 사용 설정을 열고 Blackout을 허용합니다.

macOS 13 이상, Apple Silicon 및 Intel Mac을 지원합니다. 터미널이나 개발 도구는 필요하지 않습니다.
현재 배포본은 로컬 서명이며 Apple 공증을 받지 않았습니다. 실행이 차단되면 출처를 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안**에서 직접 허용하세요. Gatekeeper를 끌 필요는 없습니다.

## 사용

- **검은 화면 시작:** Control + Option + B 또는 메뉴 막대 Blackout → 지금 화면 가리기.
- **상태 아이콘:** 열린 자물쇠는 앱 비밀번호 보호 꺼짐, 닫힌 자물쇠는 켜짐을 뜻합니다. 비밀번호 설정을 저장하면 즉시 바뀝니다. 화면 차단 중에는 메뉴 막대도 숨겨집니다.
- **해제:** 마우스를 움직이거나 클릭·스크롤·키 입력. 비밀번호 보호를 켠 경우에는 비밀번호를 입력해야 합니다.
- **비밀번호:** 설정에서 보호를 켜고 새 비밀번호와 확인을 입력한 뒤 저장합니다. 변경·해제할 때는 현재 비밀번호가 필요합니다.
- **자동 실행:** 설정에서 로그인 시 자동 실행을 켭니다. 로그인 후 메뉴 막대에서 대기하며, 화면을 자동으로 검게 만들지는 않습니다.
- **언어:** 기본값은 OS 언어입니다. 설정에서 32개 언어 중 선택하면 즉시 적용됩니다.
- **입력 언어 전환:** 해제창에서 Control + Space를 누르면 활성화한 키보드 입력 소스를 전환합니다.

## 입력 차단과 한계

입력 차단 권한이 없거나 차단을 시작하지 못하면 검은 화면을 띄우지 않습니다. 차단 중에는 원본 키보드·마우스 이벤트를 소비하고, 해제창에 필요한 입력만 Blackout에 전달합니다. 차단이 중단되면 화면을 다시 보여주고 오류를 알립니다.

앱 내부의 화면 가리기 기능이므로 macOS 보안 잠금을 대체하지 않습니다. 강제 종료, 다른 권한 있는 프로그램, macOS 보안 화면·보안 입력은 운영체제가 제어합니다. 다른 사람의 Mac 접근을 막아야 한다면 **Control + Command + Q**로 macOS를 잠그세요.

비밀번호 원문은 저장하지 않으며 무작위 salt와 PBKDF2 검증값을 사용합니다. 설정은 이 Mac에 저장되고, 앱 자체의 서버·분석 수집 기능은 없습니다.

소스 빌드, 검증, 비밀번호 초기화, 삭제는 [개발자 문서](../development.md)를 참고하세요.
